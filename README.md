# Proyecto UTN: Análisis Demográfico y de Impacto Social
Este repositorio documenta el desarrollo completo de un trabajo práctico de análisis de datos enfocado en el estudio de registros demográficos, con el propósito central de explorar un impacto social mediante el procesamiento masivo de información.
----
## Enfoque e idea principal
El objetivo de este proyecto no fue solo aplicar técnicas de programación, sino **encontrar una visión y lectura social** en paralelo dentro de los datos. A través de este macroanálisis, se buscó transformar registros numéricos en indicadores significativos que reflejan realidades demográficas concretas.

----

## Estructura y Desarrollo del Análisis (Google Colab)
El desarrollo técnico se estructuró de manera sistemática en un cuaderno de python:

1. **Importación de Librerías:** Carga de las herramientas fundamentales para la manipulación y visualización de datos.
2. **Exploración Inicial del Dataset:**Inspección de las dimensiones, tipos de datos y reconocimiento general de la estructura del archivo CSV.
3. **Limpieza y Preparación de datos:**
   * Tratamiento y control de valores nulos.
   * Normalización y renombrado de columnas para una lectura limpia.
   * Ajustes y filtrados para garantizar la consistencia analítica.
4. **Análisis Estadístico y Gráficos:** Generación de visualizaciones en Python para interpretar tendencias y patrones a lo largo de los años y departamentos.

----

## Visualización Interactiva (Power BI)
Como complemento visual y para potenciar la toma de decisiones, se desarrolló un tablero interactivo en Power BI:
* **Diseño estético optimizado:** Tarjetas de KPI ajustadas, esquinas redondeadas, sombras y limpieza de marcos para una experiencia moderna.
* **Monitoreo dinámico:** Permite cruzar las variables analizadas para observar el comportamiento de los datos de manera intuitiva.
